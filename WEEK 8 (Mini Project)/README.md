# E-Commerce Order Analytics System

## Overview
This project demonstrates an end-to-end E-Commerce Order Analytics System built using **Python** and **SQLite**. It includes data generation, data cleaning, SQL-based business analysis, a command-line reporting tool, and edge case validation.

## Features
- Generate synthetic e-commerce datasets (500+ records per table)
- Clean and validate raw data using Python
- Load cleaned data into SQLite
- Perform 16 SQL business analysis queries
- Generate date-range based sales reports
- Test edge cases to ensure data integrity

- Faker
