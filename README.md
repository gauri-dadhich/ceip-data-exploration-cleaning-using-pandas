# CEIP Summer Internship – Data Exploration and Cleaning using Pandas

## Objective
To perform basic data exploration and data cleaning operations using Python Pandas.

## Dataset
- Ecommerce Dataset
- Selected one combined CSV file from the provided ZIP dataset

## Tasks Performed
1. Loaded CSV dataset into Pandas DataFrame
2. Explored dataset using:
   - head()
   - tail()
   - shape
   - columns
   - dtypes
3. Handled missing values using fillna()
4. Filtered rows based on:
   - discount > 50
   - rating > 4
5. Selected required columns
6. Removed duplicate rows
7. Created derived columns:
   - quantity
   - total_amount
8. Saved cleaned dataset as CSV

- Data_Cleaning.ipynb
- cleaned_ecommerce_dataset.csv
